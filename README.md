# SLearn

SLearn is a classroom learning hub for teachers and students.

Teachers can create classrooms, approve join requests, publish exercises, and review learning analytics. Students can join with a class code, wait for approval, complete exercises, and follow their own progress.

## Website and installable app

Use SLearn directly at https://hackathon-mmu-2026.web.app or install it as a desktop-style Progressive Web App. In Chrome or Edge, open the site and choose **Install SLearn** from the address bar, browser menu, or the in-app **Install app** button. The installed version opens in its own window and uses the same Firebase account and classroom data as the website.

## Offline exercises

When a student is online, SLearn caches assigned exercises in the background. Cached classrooms and exercises remain available without a connection. Normal and personalized exercise submissions are saved on the device with a **Waiting to sync** status, retried every 15 seconds while online, and retried immediately when connectivity returns. Students should open SLearn online once before relying on an exercise offline, and should keep the same browser profile/device until queued answers have synced.

Personalized exercises are generated by Vertex AI from the learner's previous marked results. Learners scoring at least 60% share a reinforcement set; learners below 60% receive an individual set focused approximately 70% on weak topic tags and 30% on general reinforcement. Personalized generation is quota-free by default; future enforcement can be enabled server-side with `PERSONALIZED_QUOTA_ENABLED=true`.
